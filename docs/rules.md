## 第一部分：阅卷人视角下的考场八大军规与避雷指南

| 维度 | ✅ 核心规范与踩分标准 | ❌ 常见考场雷区与批注警告 |
|:---|:---|:---|
| **一、标题与案名** | 标题居中，自拟带书名号的个性名称，末尾必须有“策划案”字样。格式：《【主标题】——【副标题】》策划案 | 缺少自拟名称；漏写书名号；漏写“策划案”；字迹潦草不居中 |
| **二、背景与发起句** | 三维立体展开（国家战略+时代特征+市场受众）。末段必须有**承上启下发起句**：“XX平台拟于某年某月某日举办……旨在……” | 干瘪抄写百科常识；前后逻辑割裂；缺少发起句导致入题生硬 |
| **三、专业术语与量词** | 综艺/真人秀/视听节目用**“期”**；纪录片/电视剧用**“集”**；直播用**“直播场地”**，录播用**“录制地点”**；时长用**“分钟”** | 综艺节目通篇写“集”；时长写“一个半小时”；直播写“录制地点” |
| **四、文风与措辞** | 客观严谨、文字饱满、富有视听专业术语。用词平实准确 | **严禁绝对化广告禁用词**（“首创、顶级、唯一、独家”）；**严禁“尊己卑人”**（贬低同类节目） |
| **五、受众画像精细化** | 严格区分**核心受众**与**次要/辐射受众**，列出具体年龄段、生活痛点与媒介接触习惯，并陈述定位原因 | 泛泛而谈写“适合全国人民大众”、“12-65岁所有观众”，判无效受众 |
| **六、规则与内容具象化** | 拒绝抽象概念，必须写出具体的任务规则、考核指标、积分机制或分镜头画面 | 只写“嘉宾进行小游戏”、“完成任务挑战”，缺乏具体规则落地 |
| **七、提纲设问规范** | 谈话/访谈/交流提纲**必须使用具体的3~5个递进式问句（带问号）**呈现 | 用陈述句罗列话题；只写“1.开场 2.提问 3.回答 4.总结”会判严重低分 |
| **八、前后逻辑自洽** | 前后呼应：前面提了XR虚拟技术，后文节目单和看点中必须有扎实落地；主题词贯穿始终 | 前后矛盾、虎头蛇尾；前面列举宏大概念，后文具体环节完全脱节 |

## 第二部分：广电与网络视听政策红线速查

策划案答题与立项必须紧密契合国家广播电视总局政策风向，避免产生“战略性失误”：

### 1. 文艺节目与人员管理规范（广电办发〔2021〕267号通知）
- **严格人员政治与道德把关**：坚决抵制违法失德人员、有丑闻劣迹者登台出镜。
- **坚决破除唯流量论**：
  - **严禁**播出偶像养成类节目。
  - **严禁**明星子女参加综艺与真人秀。
  - **严控**投票打榜机制，严厉遏制不良“饭圈”文化与集资打投。
- **坚决抵制泛娱乐化**：
  - 杜绝“娘炮”等畸形审美。
  - 坚决抵制炫富享乐、绯闻隐私、低俗网红、无底线审丑。
- **推行主持人“持证上岗”**：
  - 严格执行主持人资质管理，**严禁使用非专业艺人作为“嘉宾主持”**主持节目。
- **严格控制片酬与制作成本**：坚决遏制明星“天价片酬”，鼓励资源向基层主创与技术创新倾斜。

### 2. 广电媒体深度融合意见（广电发〔2020〕79号通知）
- **全媒体传播格局**：推动“一云多厨房”、台网双跨、县级融媒体纵向贯通。
- **高新视听赋能**：大力推进超高清（4K/8K）、5G高新视频、XR扩展现实、沉浸式互动、虚拟人制作。
- **主流价值驾驭算法**：抢占网络视听意识形态主阵地，用主旋律引领网络大流量。

## 第三部分：工业级视听与制作参数库

### 1. 工业级十机位调度规范参数库

在策划案“摄制策略”或“机位调度”板块，直接调用此标准十机位方案：

| 机位编号 | 机位类型 | 镜头景别与运镜 | 核心拍摄功能与画面任务 |
|:---:|:---|:---|:---|
| **1号机位** | 主机位（中央偏左） | 中景、近景、特写 | 抓取舞台核心人物/主持人正面半身及面部表情 |
| **2号机位** | 全景机位（中央正后方） | 远景、大全景 | 交代舞台整体全貌、舞美灯光空间关系与大型调度 |
| **3号机位** | 主机位（中央偏右） | 中景、特写 | 抓取受访者/次要主角面部微表情，与1号机位形成景深互切 |
| **4号机位** | 全景侧位（舞台侧前方） | 全景、大半身 | 交代舞台纵深感与演员侧向调度动线 |
| **5号机位** | 观众席反打机位（左侧） | 中景、全景 | 捕捉现场观众鼓掌、欢呼、流泪等真实即时情绪反馈 |
| **6号机位** | 观察席/评审席机位（右侧） | 特写、反应镜头 | 抓取专家观察员、评委评审席的第一反应镜头 |
| **7号机位** | 穿戴式稳定器游机（Steadicam） | 移动跟拍、主观视角 | 穿梭于舞台或实景之间，近距离抓取动态细节与突发状况 |
| **8号机位** | 手持流动游机（轻量化微单） | 贴身抓拍、倾斜构图 | 深入后台、侧台候场区，抓取真实鲜活的候场纪实细节 |
| **9号机位** | 遥控滑轨机位（舞台前沿低角度） | 仰拍、低角度平移 | 增强视觉张力，渲染歌舞或竞技对抗的动感节奏 |
| **10号机位** | 大臂重型摇臂 / 4K无人机航拍 | 俯拍运动、大范围回旋 | 提供宏大俯瞰视角与气势磅礴的大转场镜头 |

### 2. 舞美灯光系统工程参数

- **基础照明光**：
  - **面光**：科学布设于舞台正前方，色温5600K，保障主持人与演员面部基础照度，色彩真实还原。
  - **逆光（轮廓光）**：布设于舞台后上方，勾勒人物边缘发丝与肩膀轮廓，强化人物与背景的分离度与空间立体感。
  - **侧光（造型光）**：消除阴影死角，塑造演员肌肉与服饰质感。
- **效果气氛光**：
  - **电脑摇头图案灯（Spot）**：用于投射几何光斑、主题纹理与舞台地面动效。
  - **电脑染色灯（Wash）**：进行大面积冷暖色温转换与情感色彩渲染（如庄重红金、科技冷蓝、温情暖黄）。
  - **激光与光束灯（Beam）**：用于高潮段落的空中光网交织，强化视觉冲击力与现代节奏感。
